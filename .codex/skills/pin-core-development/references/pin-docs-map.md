# Pin 文档索引

`docs` 是独立文档仓库：`https://github.com/ipiner/docs`。文档不是源码签名的替代品，改代码时仍以 `pin/src` 和测试为准。

| 任务 | 文档 |
| --- | --- |
| 安装、Application 集成、版本要求 | `guide/getting-started.md` |
| 模块、领域、Controller、Model、Factory、Action 自动推导 | `guide/module.md` |
| Model 基类、事件、缓存、软删除、ID 和可查询模型 | `model/index.md`、`model/cache.md` |
| ModelService、CRUD、事务、生命周期、乐观锁、Result | `model/service.md` |
| Queryable、排序、分页和查询规则 | `model/queryable.md`、`features/validation.md` |
| Action 生命周期、验证、上下文、Fake | `features/action.md` |
| 路由枚举、处理器、属性、注册、测试 | `features/routing.md` |
| Controller、ApiResponse、错误响应 | `features/controller.md`、`features/response.md` |
| 错误码、异常和错误注册 | `features/errors.md`、`features/exception-handler.md` |
| HTTP 测试和断言 | `testing/http-tests.md`、`testing/helpers.md` |
| 数据库迁移和 Seeder | `database/migration.md`、`database/seeder.md` |
| 包能力和扩展功能 | `packages/*.md`、`security/*.md`、`digging-deeper/*.md` |

对应的在线文档入口是 `https://ipiner.cn`；URL 路径通常与表中的 Markdown 路径一致。
